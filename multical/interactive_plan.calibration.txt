# Plan for interactive multical calibration:

Here’s a tight, end‑to‑end playbook for finding, visualising, and pruning bad Charuco‑corner observations while you run multical, wired so that each step can be driven from a Jupyter notebook or a thin Dash/Gradio front‑end.

🗺️ Workflow outline

Phase	Goal	Key artefacts
1. Detect + cache	Run multical calibrate --cache_detections so every corner lands in calibration.detections.pkl (numpy structured array).	raw detections
2. Solve (all data)	Call the bundle adjuster with Soft‑L1 (δ≈1 px) and log residuals via Problem::Evaluate() or SciPy’s least_squares callback.	residuals.npy, weights.npy
3. Diagnose	Plot residuals ↔ radial‑dist, histograms, image overlays; flag outliers.	interactive notebook
4. Cull	Drop rows whose weight < τ or	r
5. Iterate	Repeat 2–4 until the tail vanishes and graph remains connected.	final calibration.pkl
🔍 Phase‑by‑phase details
1 ⃣ Detection cache
multical already serialises a detections.pkl workspace that stores (camera, frame, board_id, corner_id, u, v). Operating on that file keeps the expensive Charuco detection outside the loop.​

Plotly’s `on_click` and ipywidgets’ `interact` let you flag a point and push its index onto a **“ban‑list”** slider or checklist widget.﻿ :contentReference[oaicite:5]{index=5}  

### 4 ⃣ Outlier culling logic
* **Weight rule:** drop any observation with \(w_i<0.2\) (~ |r| > 2.2 px under Soft‑L1).  
* **Sigma rule:** compute robust σ (MAD) and cut |r| > 3 σ.  
* **Connectivity guard:** before each solve, verify that the board–camera graph is still one connected component; if not, lower the threshold or keep the edge.﻿ :contentReference[oaicite:6]{index=6}  

Store the mask in `workspace.detections["keep"]` so you can toggle it interactively.

### 5 ⃣ Iterate until convergence
Each loop should shrink:

max|r| : 1600 → 30 px 95‑pct : 0.9 → 0.4 px tail : single‑point → none

Copy code

If the 95‑percentile plateaus while max|r| keeps falling, you’re done—the last big spike was the only real outlier.

## 🛠️ Reusable helper scripts

| Script | Purpose |
|--------|---------|
| `dump_residuals.py` | Save residuals, weights, and lookup metadata after any multical solve. |
| `plot_residuals.ipynb` | Live widgets (Plotly & ipywidgets) to explore, click, and ban points. |
| `recalibrate.py` | Reads `banlist.json`, filters detections, reruns `workspace.optimize()`, writes new residuals. |
| `graph_check.py` | Warn if any camera or board is disconnected after masking. |

All four scripts are <100 lines each and chain through a Makefile so `make refine` loops until no new bans appear.
